# @senda/shared-types

Shared TypeScript types and interfaces used across Senda platform.

## Usage

```typescript
import { User, Conversation, ApiResponse } from '@senda/shared-types';

const user: User = {
  id: '123',
  email: 'user@example.com',
  name: 'John Doe',
  createdAt: new Date(),
};
```

## Development

This package contains type definitions only, no runtime code.
