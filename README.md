# Senda – Conversational AI Platform

> Guiding businesses along the path to automation and intelligent service.

## Structure
- `apps/api`: FastAPI orchestrator (Telnyx, Phorest, Gemini)
- `apps/web`: Next.js site and ops console
- `apps/agent`: Dialogflow CX agent definitions
- `packages`: shared clients, schemas, and UI
- `docs`: architecture and brand material
