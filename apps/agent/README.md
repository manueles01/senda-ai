# Senda Agent

Dialogflow CX agent definitions for conversational AI.

## Structure

- `intents/`: Intent definitions
- `flows/`: Conversation flow definitions
- `webhooks/`: Webhook configurations

## Development

This directory contains the Dialogflow CX agent configuration files that can be:
- Exported from Dialogflow CX console
- Version controlled
- Deployed via CI/CD

## Deployment

Use the Dialogflow CX API or console to import/export agent definitions.
